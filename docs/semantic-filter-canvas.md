# 语义筛选画布

## 数据边界

- 筛选属性只来自语义单位绑定的普通 Markdown 文件。
- 未绑定 Markdown、绑定失效或字段块无法读取的单位不会进入属性筛选结果。
- 不读取语义单位自身的 `tags`、`properties` 或 `owner` 兼容字段。
- 查询只读取被语义单位直接引用的 Markdown，不扫描或重写整个仓库。

## 临时只读画布

- 从“管理画布”进入，不附加到普通二维画布。
- 结果使用语义单位规范内容生成只读 SVG 预览，不登记同步实例。
- 单位内部成员不接收选择、编辑、删除或链接激活操作。
- 只允许整体拖动单位，以及平移、缩放临时画布。
- 筛选条件、单位位置、缩放和平移状态只存在于当前页面内存；关闭页面后不保存。
- Markdown 属性或语义单位规范内容变化时，当前页面自动重新查询并刷新。

## 安全保证

- 不修改 Markdown 文件。
- 不修改任何已有二维或三维画布。
- 不修改语义单位定义、成员映射或同步实例。
- 不影响普通二维画布中的跨画布同步流程。

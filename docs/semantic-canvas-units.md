# 画布语义单位：架构与数据安全基线

## 目标模型

- 语义单位是全局定义，不绑定某一张二维画布。
- 每个单位具有名称、可选 Markdown 绑定、标签、属性、归属和版本化规范内容。
- 画布中保存的是单位实例。实例拥有独立的外部位置，但同步实例共享同一份规范内容。
- 只有“引入同步实例”会登记同步关系；普通 Ctrl+C/V 产生的新元素 ID 不进入实例注册表。
- “创建独立副本”会创建新的单位 ID 和实例 ID，与来源单位彻底解除关联。

## 身份与复制边界

语义身份以插件数据中的 `unit -> instance -> memberElementIds` 注册表为准，不依赖可被剪贴板复制的元素 `customData`。规范成员使用稳定的 `memberId`，每个实例再映射到该画布中的真实 Excalidraw 元素 ID。这一设计保证普通复制粘贴不会意外成为同步实例。

## 持久化边界

- 新增独立的 `semanticUnits` 数据命名空间，不与 Excalidraw、Knowledge Map 或 Markdown 字段数据互相覆盖。
- 加载未知的未来数据版本时停止加载，不用空对象覆盖原数据。
- 每次数据变更先在内存副本上执行，持久化成功后才替换当前状态。
- 规范内容使用乐观版本号；过期实例不能覆盖更新后的单位。
- 解除单位或实例只删除语义注册信息，不删除画布元素、Markdown、图片或附件。
- 缺失成员只记录诊断状态，不自动清理或重写画布。

## 画布写入原则

- 不扫描、转换或重写没有语义单位的既有画布。
- 创建初始单位时优先只登记现有元素 ID，不改写元素内容。
- 任何新增同步实例、同步更新或显式成员修改前，必须先备份目标画布并校验原内容哈希。
- 关闭状态的画布默认记录待同步版本，待安全打开后应用；在验证完整的事务式文件更新前，不后台静默重写。
- 高亮、边界背景和筛选预览使用临时覆盖层，不写入持久画布元素。
- 成员高亮是一次性查看提示；开始下一次拖拽、滚轮缩放或键盘操作时立即消失，避免覆盖层与移动后的元素错位。
- 单位状态不得通过 `isDeleted` 实现。

## Stage 2 显式跨画布引入

- 仅通过二维画布空白处右键的“引入同步实例”登记共享同一单位的实例。
- “创建独立副本”生成新的单位 ID 与实例 ID，后续与来源单位互不关联。
- 普通 Ctrl+C/V 不读取或写入语义注册表，因此不会形成同步关系。
- 引入时重新生成画布元素、组合与图片资源 ID，同时恢复成员相对位置和内部绑定。
- 写入目标画布前先创建并校验逐字节备份，再核对源文件哈希；任何检查失败都停止引入。

## Stage 3 同步传播与实例生命周期

- 已登记成员的文字、样式、尺寸和相对位置变化会生成新的单位修订。
- 已打开的其他实例立即应用新修订；未打开的画布保持旧 `appliedRevision`，打开时再安全应用。
- 所有成员共同平移只更新该实例的外部原点，不改变其他实例在各自画布中的位置。
- Excalidraw Markdown 保存可能重写文字元素 ID；同步层会按单位成员、内容和相对位置修复映射，新实例直接使用兼容的八字符 ID。
- 一个实例的全部可视成员被删除后，仅自动解除该实例注册；不删除单位定义，也不影响其他画布中的实例。
- 关闭期间积累的修订会在画布首次打开并完成场景初始化后补同步；若首次就绪事件正被其他场景任务占用，会有限重试而不要求再次打开画布。
- Ctrl+S 完成画布保存后会立即冲刷待登记的单位修改；关闭视图会在销毁画布 API 前等待最后一次登记。画布每次成为活动页时都会再次检查待应用修订。

## Stage 4 单位级状态

- 锁定是语义实例状态，不改写 Excalidraw 元素的原生 `locked` 或 `isDeleted` 字段。
- 二维画布使用临时状态层阻止锁定成员被指针拖动；右键状态层可以解锁。
- 管理页面可以按锁定状态筛选，并可批量锁定或解锁一个元素单位的全部已登记实例。
- 不提供锁定快捷键，也不在通过键盘删除成员后自动恢复画布内容。
- 历史数据中的 `hidden` 字段仅为兼容旧数据而保留，界面和运行时行为均忽略该字段。

# Obsidian Knowledge Suite v1.1.1

这是一次针对3维画布交互和背景表现的小型修复更新。

## 本次更新

- 3维画布空白区域支持左键拖拽框选节点。
- 左键单击节点仍直接打开对应文件、文件夹或画布。
- 按住空格并使用左键拖拽旋转地图，页面提示同步精简。
- 框选节点后可使用 `Backspace` 或 `Delete` 将其从当前画布移除。
- 节点右键菜单新增“从本画布移除”，执行前会明确提示不会删除源文件。
- 移除插件页面中重复的画布标题、返回按钮和“创建子画布”按钮。
- 优化深空背景，增加写实月球与小型行星；各行星分散在不同三维方向，减少同一视角下的拥挤。
- 增加离线行星纹理及第三方素材来源说明。

## 安装与升级

下载 `obsidian-knowledge-suite-v1.1.1.zip`，解压后将其中的 `.obsidian/plugins` 合并到目标 Vault。升级不会覆盖插件的 `data.json` 或用户画布文件。

本版本包含：

- Knowledge Map `0.2.1`
- Excalidraw Custom `2.26.4`
- Excalidraw Core Custom `0.18.118`

发布附件同时提供 `SHA256SUMS.txt`，可用于核对下载文件完整性。

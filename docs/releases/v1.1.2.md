# Obsidian Knowledge Suite v1.1.2

这是一次针对2维画布公式输入与保存流程的小型更新。

## 本次更新

- 全局公式和行内公式都可在 Obsidian 快捷键设置中独立绑定按键。
- 全局公式改用统一的本地公式编辑器，新建时保持空白并自动聚焦输入区域。
- 编辑已有全局公式时继续使用本地编辑器，并尽量保持原来的显示尺寸。
- 新建、编辑、保存和重新载入公式时优先使用本地 SVG 渲染器。
- 修复保存含有本地公式的画布时弹出 Excalidraw Extras 安装提示的问题。

## 安装与升级

下载 `obsidian-knowledge-suite-v1.1.2.zip`，解压后将其中的 `.obsidian/plugins` 合并到目标 Vault。升级不会覆盖插件的 `data.json` 或用户画布文件。

本版本包含：

- Knowledge Map `0.2.1`
- Excalidraw Custom `2.26.4`
- Excalidraw Core Custom `0.18.118`

发布附件同时提供 `SHA256SUMS.txt`，可用于核对下载文件完整性。

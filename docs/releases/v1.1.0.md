# Obsidian Knowledge Suite v1.1.0

这是一次围绕画布组织、编辑体验和3维画布完成的大型功能更新。

## 主要更新

### 画布树与画布关系

- 2维画布和3维画布都成为独立、持久化的文件。
- 支持明确的父画布、子画布关系，子画布可以继续无限嵌套。
- 新增画布树，可折叠查看层级，并通过拖拽调整同级画布顺序。
- 引用关系与父子关系彼此独立；取消子画布后仍保留引用。
- 引用目录区分“引用了”和“被引用”，双向关系使用双箭头呈现。
- Back 会返回真实父画布；父画布已打开时保留视角，重新打开时居中入口节点。

### 右键菜单与节点外观

- 画布、文件夹、文件和普通 Excalidraw 元素使用各自适合的右键菜单。
- 右键直接识别鼠标下的目标，不再要求先选中节点。
- 菜单全面中文化并调整为紧凑的 Obsidian 风格。
- 置底、下移、上移和置顶合并为图标工具栏；上下移动会寻找最近的视觉重叠对象。
- 2维与3维节点均支持颜色、形状、自定义颜色、Lucide 图标和 Emoji。
- 自定义颜色与图标选择界面统一为居中、紧凑的卡片式设计。

### 3维画布

- 新增分层星云背景和更丰富的星空效果。
- 文件、文件夹、2维画布和3维画布使用高对比度图标节点。
- 节点支持从四条边拖拽调整尺寸，拖动中间区域仍用于移动位置。
- 3维节点拥有与2维节点一致的外观和关系菜单。
- 点击尚未建立画布的文件夹时，可选择新建2维或3维子画布。
- 当两种子画布均存在时，每次点击都会重新选择需要打开的画布，不保存默认项。

### Excalidraw 文本编辑

- 修复行内公式后方文字在双击编辑时消失的问题。
- 修复公式与后续文字之间出现超长空白及编辑错位的问题。
- 保持后续文字可输入、删除、鼠标框选及局部加粗。
- 修复上下层移动命令选中无关远端元素的问题。

## 安装与升级

下载 `obsidian-knowledge-suite-v1.1.0.zip`，解压后将其中的 `.obsidian/plugins` 合并到目标 Vault。升级不会覆盖插件的 `data.json` 或用户画布文件。

本版本包含：

- Knowledge Map `0.2.0`
- Excalidraw Custom `2.26.4`
- Excalidraw Core Custom `0.18.118`

发布附件同时提供 `SHA256SUMS.txt`，可用于核对下载文件完整性。

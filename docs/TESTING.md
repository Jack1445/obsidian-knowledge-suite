# 测试清单

## 自动检查

```bash
npm run verify:suite
npm run test:suite
npm run build:suite
npm run package:suite
```

Excalidraw Custom 的上游源码当前在新版 ESLint 类型规则下存在大量既有告警，因此不把“全仓零告警”作为首次整合门槛。该插件以正式生产构建成功、Core 嵌入签名正确和手工功能回归作为发布门槛。新增或修改的 Suite 自有代码仍不得引入新的检查错误。

## 干净安装

- 在空 Vault 中解压整合包。
- Knowledge Suite 能启用，且旧插件启用时能明确阻止初始化。
- 命令面板中出现 Knowledge Map 入口。
- 新建普通 Excalidraw 画布正常。

## 覆盖升级

- 从上一稳定版本覆盖三个程序文件。
- 两个旧插件的 `data.json` 未改变，新插件命名空间数据完整。
- 原有画布可以打开。
- 图片、字体和嵌入文件没有变成灰色占位符。

## Knowledge Map

- 根页面不显示 Vault 节点。
- 文件夹节点点击下钻。
- 文件节点点击打开笔记。
- 当前文件夹根节点连接所有直属子内容。
- 层级边和引用边颜色、线型不同。
- 拖动节点后位置保存。
- Reset layout 恢复整齐默认位置。
- 文件和文件夹拖入知识画布后生成圆形节点。
- 地球画布可以创建和进入。

## Excalidraw Custom

- 普通绘图、图形内文字和图片正常。
- 全局公式正常插入和二次编辑。
- 文本中可以插入行内公式。
- 只有公式、没有普通文字时仍然保存。
- 从外部粘贴的文字可以继续插入行内公式。
- 点击文字进入文字编辑；点击公式进入公式编辑。
- 选中部分文字后 `Ctrl+B` 只加粗选中范围。
- 退出编辑后局部粗体仍可见。
- 再次双击仍可正常编辑粗体文本。
- 右键菜单尺寸和视觉样式正常。

## Markdown 标签与属性

- 仅打开管理视图不会修改任何 Markdown 文件。
- 新建、重命名、排序、设置默认属性和删除字段定义不会批量修改文档。
- 管理表格以 Markdown 文件为行、字段为列，固定表头和文件列正常。
- 文件列仅显示图标和单行文件名，不显示路径或内部字段标识。
- 建立多个字段后同时显示多列，各列可独立拖动并在重启后保持宽度。
- 文件名、文件夹及字段组合筛选正常，并在重启插件后保留。
- 第一次设置字段值时明确提示将插入字段块。
- 默认属性在无值的现有及新建 Markdown 正文面板中可见，且仅查看不会写入文件。
- 非默认属性为空时不在正文面板显示，有值后显示，清空后再次隐藏。
- 设置字段值前创建完整原文件备份和 SHA-256 清单。
- 写入只改变 `knowledge-suite-fields` 块，块以外内容逐字节保持不变。
- 文档被外部修改时停止写入，不覆盖新内容。
- Live Preview 和阅读模式均可显示、修改字段。
- 源码模式可以直接查看和编辑字段块 YAML。
- 文本、数字、日期、单选、多选、复选框和标签控件正常。
- 重命名或移动 Markdown 文件后，管理视图和正文面板继续正常工作。
- 明暗主题、窄窗口、弹出窗口、空状态、错误状态和键盘焦点样式正常。

## 发布验收

- ZIP 内只包含 `knowledge-suite` 插件目录。
- `artifacts/knowledge-suite` 包含标准插件文件和保留的许可证。
- `SHA256SUMS.txt` 可以验证全部产物。
- 用户明确验收后才允许创建 GitHub Release。

# 测试清单

## 自动检查

```bash
npm run verify:suite
npm run test:suite
npm run build:suite
npm run package:suite
```

Excalidraw Custom 的上游源码当前在新版 ESLint 类型规则下存在大量既有告警，因此不把“全仓零告警”作为首次整合门槛。该插件以正式生产构建成功、Core 嵌入签名正确和手工功能回归作为发布门槛。新增或修改的 Suite 自有代码仍不得引入新的检查错误。

## 干净安装

- 在空 Vault 中解压整合包。
- 两个插件都能启用。
- 命令面板中出现 Knowledge Map 入口。
- 新建普通 Excalidraw 画布正常。

## 覆盖升级

- 从上一稳定版本覆盖三个程序文件。
- 两个插件的 `data.json` 未改变。
- 原有画布可以打开。
- 图片、字体和嵌入文件没有变成灰色占位符。

## Knowledge Map

- 根页面不显示 Vault 节点。
- 文件夹节点点击下钻。
- 文件节点点击打开笔记。
- 当前文件夹根节点连接所有直属子内容。
- 层级边和引用边颜色、线型不同。
- 拖动节点后位置保存。
- Reset layout 恢复整齐默认位置。
- 文件和文件夹拖入知识画布后生成圆形节点。
- 地球画布可以创建和进入。

## Excalidraw Custom

- 普通绘图、图形内文字和图片正常。
- 全局公式正常插入和二次编辑。
- 文本中可以插入行内公式。
- 只有公式、没有普通文字时仍然保存。
- 从外部粘贴的文字可以继续插入行内公式。
- 点击文字进入文字编辑；点击公式进入公式编辑。
- 选中部分文字后 `Ctrl+B` 只加粗选中范围。
- 退出编辑后局部粗体仍可见。
- 再次双击仍可正常编辑粗体文本。
- 右键菜单尺寸和视觉样式正常。

## 发布验收

- ZIP 内包含两个完整插件目录。
- 两个独立 `artifacts` 目录均只有标准插件文件。
- `SHA256SUMS.txt` 可以验证全部产物。
- 用户明确验收后才允许创建 GitHub Release。

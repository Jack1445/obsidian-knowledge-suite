# 功能概览

本文面向第一次接触项目的使用者和开发者。

## Knowledge Map

Knowledge Map 把 Obsidian 的真实文件夹和文件转换成可浏览的知识地图：

- 进入文件夹时自动生成以当前文件夹为根节点的地图。
- 根节点位于上方，子文件夹和子文件整齐排布在下方。
- 点击文件夹节点继续下钻，点击文件节点打开对应笔记。
- 文件夹所属关系与笔记引用关系使用不同颜色和线型。
- 节点拖动后的位置会持久保存。
- 可以恢复当前文件夹的默认布局。
- 可以新建知识画布，并把文件或文件夹拖入画布。
- 支持 2D 地图和地球画布。

## Excalidraw 画布能力

定制版保留 Excalidraw 原有绘图、文字、图形绑定、图片、链接和菜单能力，并加入：

- 知识地图文件和文件夹节点。
- 点击节点主体直接打开或下钻。
- 块级公式编辑。
- 文本中的行内公式。
- 双击行内公式重新编辑 LaTeX。
- 选中文字后局部加粗。
- `Ctrl+B` / `Cmd+B` 局部加粗快捷键。
- 编辑结束后仍保持局部加粗的正式画布渲染。
- 更紧凑、清晰的画布右键菜单。

## Excalidraw Core Custom

Core 是 Excalidraw Custom 的内部依赖，负责文本排版、行内公式、局部样式、Canvas 渲染和 SVG 导出。普通用户不需要单独安装 Core。

## Markdown 标签与属性

标签与属性功能只管理 Markdown 文档，不会在扫描、启动或创建字段时自动改写已有文件：

- 独立管理视图以 Markdown 文件为行、自定义字段为列。
- 文件列只显示原生文档图标和文件名；每个字段独立成列并可拖动调整宽度。
- 支持文本、数字、日期、单选、多选、复选框和标签字段。
- 字段只需填写名称和类型，内部稳定键自动生成且不出现在界面中。
- 字段只能在管理视图中建立；正文面板只负责查看和修改已有字段值。
- 使用 `knowledge-suite-fields` 正文代码块保存值，不改写原有正文或 YAML Properties。
- Live Preview 和阅读模式会在正文顶部显示可直接编辑的字段面板，无需手工插入面板。
- 设为“默认属性”的字段即使为空，也会出现在现有及新建 Markdown 的正文面板中；其他字段仅在有值时显示。
- 空的默认属性只是界面展示，不会因此改写文档；第一次填写具体值时才安全写入字段块。
- 每次字段写入前备份完整原文件，并检测并发修改，避免覆盖较新的内容。
- 删除字段只删除字段定义，不会批量修改或删除 Markdown 中已有的值；同名重建会继续关联原有值。
- 管理视图支持文件名、文件夹和组合字段筛选，并记忆筛选条件。
- 文件列和各字段列的宽度保存在插件数据中，重新打开后继续沿用。
- 元数据读取和筛选接口与 UI 解耦，后续二维、三维画布可以复用同一套结果。

字段块示例：

````markdown
```knowledge-suite-fields
年份: 2025
发表状态: 已发表
领域:
  - 机器人
  - 触觉
标签:
  - VLA
```
````

## 统一插件架构

Knowledge Map 负责 Obsidian 文件语义、地图生成、下钻和画布管理；Excalidraw 画布模块负责通用编辑与渲染。两者现在由同一个 `knowledge-suite` 插件生命周期、数据协调层和发行包统一管理，不再作为两个插件安装或互相调用。

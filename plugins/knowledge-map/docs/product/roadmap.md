# Roadmap

## 0.1 — Folder-aware 2D map

- Vault root and folder maps
- Folder drill-down and breadcrumbs
- Note opening
- Resolved note-link edges
- Persistent node coordinates and viewport
- Live vault refresh
- Theme-aware graph controls

## Later milestones

- Search, tag filtering, attachments, unresolved links, and richer grouping
- Explicit semantic parent-child relations
- Entity and field management table
- Plant-and-vine hierarchy renderer
- Lazy-loaded 3D globe with saved latitude and longitude
- Performance work for very large folders and mobile devices
